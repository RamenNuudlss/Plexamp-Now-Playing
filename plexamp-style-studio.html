Send looks straight to OBS

The Studio talks to OBS's built-in WebSocket server. It's off by default:

  1. In OBS, open Tools → WebSocket Server Settings.
  2. Tick Enable WebSocket server, then click Show Connect Info.
  3. Copy the Server Password into the box below.
